# たるとのゲームひろば

たるとと仲間たちのゲームをまとめたゲームポータルです。

## 収録ゲーム

- たるとの大冒険2 ― たるととカモさん
- たるとの大冒険3 ― たるとの大暴走
- たるとのリズムパーティ（開発中）

ポメラニアンの「たると」が主役の、ブラウザで遊べる横スクロールアクションゲームです。

`index.html` をブラウザで開くと遊べます。ローカルサーバーを使う場合：

```bash
python -m http.server 8000
```

`http://localhost:8000` を開いてください。

## 操作

- Space / ↑（W）: ジャンプ
- X / K: 必殺技「くるん回し蹴り」
- スマートフォン: 画面下のボタン

たるとは自動で右へ走ります。プレイヤー操作はジャンプとキックだけです。お留守番がさみしくなったたるとは、苦手なのらねことカラスを避け、大好きなカモさんに助けてもらいながら、とーちゃんとかーちゃんを探しに出発します。

## スコア

- 野良ねこを倒す：100点
- カラスを倒す：200点
- ホネッコを取る：50点
- にんじんトイを取る：100点＋ライフ1回復
- カモさんを初めて踏む：150点＋大ジャンプ
- ゴール時の残り時間：0.1秒につき1点

ライフは最大3つです。川に落ちたり敵に触れたりすると1つ減り、0になるとスコアや取得アイテムを含めておうちから再スタートします。ステージは以前の2倍の長さです。
