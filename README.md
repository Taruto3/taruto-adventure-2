# たるとの大冒険2

ポメラニアンの「たると」が主役の、ブラウザで遊べる横スクロールアクションゲームです。

`index.html` をブラウザで開くと遊べます。ローカルサーバーを使う場合：

```bash
python -m http.server 8000
```

`http://localhost:8000` を開いてください。

## 操作

- Space / ↑（W）: ジャンプ
- X / K: 必殺技「くるん回し蹴り」
- スマートフォン: 画面下のボタン

たるとは自動で右へ走ります。プレイヤー操作はジャンプとキックだけです。スタート後にタイトルと物語が表示され、おうちから出発します。5個のにんじんのぬいぐるみと3本の骨を集め、とーちゃんとかーちゃんが待つゴールを目指します。カラスと野良ねこは前方への「くるん回し蹴り」、または上から踏みつぶして倒せます。広い川は手前から上段コースへジャンプして渡り、落ちるとライフを1つ失います。特に3つ目は幅900pxで、4つの上段足場を通る必要があります。水面のカモは味方で、上から踏むと通常より高く大ジャンプできます。
